# Minecraft Survival Bot

An autonomous Minecraft survival and farming bot built with Mineflayer.

## Features

- 16-chunk movement radius around its home area
- Finds grass and collects wheat seeds
- Finds water
- Creates farmland near water
- Plants and harvests wheat
- Chops trees for wood
- Collects saplings
- Replants trees
- Crafts basic wooden tools
- Replaces basic tools when needed
- Collects nearby dropped items
- Eats when hungry
- Remembers important locations
- Detects when it gets stuck
- Reconnects after disconnects
- Avoids sprinting by default
- Keeps a persistent memory file
- Uses a priority-based task system
- Records basic task successes/failures for bounded learning
